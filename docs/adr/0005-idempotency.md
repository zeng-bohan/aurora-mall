# 0005 — 统一幂等组件

日期：2026-09-28 · 状态：Accepted

## Context

支付回调重试、MQ 重复消费、用户重复下单三处都需要幂等。散装 if 判断不可复用也不可讲述。

## Decision

- 实现**统一幂等组件**：自定义注解 `@Idempotent` + AOP，按场景选策略
- 策略映射：支付回调 = 状态机 + DB 唯一索引；MQ 消费 = 去重表；下单 = 请求 ID + Redis（SETNX + 过期）
- 组件放 `aurora-common`，业务侧一行注解接入

## Consequences

- 组件本身成为可单独展示的基础设施作品
- 策略选择错误（如高频场景用 DB 唯一索引）会成瓶颈——文档需写清各策略适用边界
