# 0008 — 手写组件三部曲：ID 生成器 / 限流熔断 / RPC

日期：2026-09-28 · 状态：Accepted

## Context

核心要求是"知其所以然"。只用现成组件则核心中间件是黑盒；全部自研则周期失控。

## Decision

手写三个组件，均为独立 Maven 模块（库形态，见 ADR-0002），各有独立 README + 设计文档：

1. **`aurora-id-generator`**：号段模式 + 雪花改进（时钟回拨处理），M2 起为订单号供号
2. **`aurora-ratelimit`**：滑动窗口 + 令牌桶限流器与简易熔断器，接入网关与秒杀
3. **`aurora-rpc`**：动态代理 + Netty + 序列化 + 注册中心对接 + 负载均衡 + 自定义协议，与 OpenFeign **可切换并跑**（配置开关）

明确不做：自研注册中心（SCA 生态对接成本 > 收益）。

## Consequences

- RPC 与 OpenFeign 并跑需抽象调用层接口，M3 前的代码要为此留缝
- 三个组件构成"读过源码级理解"的实证，是项目对外讲述技术深度的核心部分
